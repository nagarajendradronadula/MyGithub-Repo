In earlier chapters, we’ve dealt mostly with functional React components that do not require state management. This chapter focuses on state, its management, and components that utilize it in React.

What is State?

State is a JavaScript object that stores a component’s dynamic data and determines its behavior. Because state is dynamic, it enables a component to track changing information between renders, making it interactive.

State is similar to props but is private to a component and solely controlled by it. Props are read-only, whereas state is mutable within the component.

Adding State to a Class Component

          
            class Greeting extends React.Component {
              render() {
                return <h1>I’m a component in need of some state! </h1>;
              }
            }

Adding state to the Greeting component involves defining a constructor function and assigning initial state using this.state. 

          
            class Greeting extends React.Component {
              constructor(props) {
                super(props);
                this.state = { name: 'Jane Doe' };
              }
              render() {
                return <h1>Hello { this.state.name }</h1>;
              }
            }
